# Vyzhenka Trails

3D trail map and mini navigator for walks from the Kazka hotel in Vyzhenka (Vyzhnytsia National Park, Chernivtsi oblast, Ukraine).

Open on a phone over HTTPS (GitHub Pages) to use GPS and the compass. Everything is in one self-contained `index.html`.

- Map data © OpenStreetMap contributors (ODbL)
- Elevation: AWS Terrain Tiles (SRTM and other open sources)
- Photos: Wikimedia Commons contributors, CC BY-SA (credited in the page)
